# Insta Public Explorer (Demo)

A lightweight Instagram-inspired demo web app UI where users can:

- Search demo public accounts.
- Preview stories and posts.
- Download media via browser download links.

## Run locally

Because this is a static app, run any static server from this folder.

### Option 1: Python

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

### Important

This demo uses static sample data and does **not** connect to Instagram.
For production, use official Meta/Instagram APIs and comply with platform terms and copyright/privacy rules.
